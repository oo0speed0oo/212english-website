Put audio clips (mp3 files) for homework/test questions here.

How it works:
- In homework-content.csv, the "audio" column holds a filename, e.g. hello.mp3
- That file must sit in this folder, named EXACTLY the same (spelling, no
  spaces instead of dashes, etc.) - "hello.mp3" in the CSV must match
  "hello.mp3" here.
- Not every question needs audio - leave the "audio" column blank for
  questions that don't have a sound clip.

This file (README.txt) is just a placeholder so this empty folder gets
saved in git. It's safe to leave it here even after you add real mp3 files.
